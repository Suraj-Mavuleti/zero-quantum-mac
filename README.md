# Zero Quantum Mac

A tensor network contraction engine for quantum circuits.

## Overview
This repository contains the highly-optimized native core for the zero quantum mac platform. It is built with zero-cost abstractions, direct hardware access, and massive internal C++ vendoring for algorithmic superiority.

## Key Advantages
- Simulates up to 40 qubits
- Complex multi-dimensional array math
- Hardware-accelerated matrix multiplication.

## Why zero-quantum-mac? (Competitive Edge)
**The Problem:** Qiskit relies on heavy Python backends and bloat. zero-quantum uses raw AVX-512 vectorization for rapid quantum simulation on classical hardware.

**The Solution:** zero-quantum-mac provides an entirely distinct, low-level architectural approach. By discarding heavy runtimes, web-views, and telemetry dependencies, we achieve maximum computational throughput and deterministic execution.
